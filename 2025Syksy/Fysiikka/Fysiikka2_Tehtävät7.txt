Tehtävä 21.
	Värähtelijän massa = 0,7 kg = m. Jousivakio = 4,0 N/m = k. Vastuskerroin = 0,9 kg/s = 𝛽. Pakkovoima = (0,50 N)∙sin(2πft) = 𝐹. 
	Vaimennuskerroin = 𝛽/2m = 0,9 kg/s / 1,4 kg = ~0,64 1/s = 𝛿
	𝜔0 = √(k/m) = √(4 N/m / 0,7 kg) = ~2,39 1/s = 𝜔v,res.  
	𝜔res = √[(𝜔0)^2 − 2(𝛿^2)] = √[(~2,39 1/s)^2 − 2(~0,41 1/s)] = √(~5,71 1/s − ~0,83 1/s) = √(~5,03 1/s) = ~2,24 1/s
	Amplitudiresonanssi taajuus = 𝜔res / 2 / π = ~2,24 1/s / 2 / π = ~0,3570 1/s^2
	Nopeusresonanssi taajuus = 𝜔v,res / 2 / π = ~2,39 1/s^2 / 2 / π = ~0,3804 1/s^2
